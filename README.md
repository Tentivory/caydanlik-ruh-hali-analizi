# ÇAYDANLIK RUH HALİ ANALİZİ

## Uluslararası Çaydanlık Ruh Hali Enstitüsü — Sürüm 7.3.1-buhar

Bu yazılım, evinizdeki çaydanlığın iç dünyasını bilimsel ciddiyetle (yani hiç bilimsel olmayan ciddiyetle) ölçer.

Çaydanlık küsmüş olabilir. Çaydanlık aşık olabilir. Çaydanlık vergi dairesinden korkuyor olabilir. Biz ölçeriz. Siz bakarsınız.

```bash
python3 caydanlik.py
```
